Claude Code is the implementation engine, not the art director.

For Dr. Wagner (`arzt`), Adler-Apotheke (`apotheke`) and Werkstatt (`werkstatt`), root-screen thumbnails MUST use existing production Gold art from CALL_ART. Emoji fallback is forbidden when production art exists.

Store missing art must render as intentional locked/missing-art design. Never make a repetitive blank-shirt grid the premium first impression.
