# Practice Product Spec

Practice is the training gym. It answers: "What should I train?"

Required hierarchy:
1. Continue / recommended practice
2. Prepare
3. Improve
4. Review
5. Library

Use current real destinations only.

Known real handlers already present in the app may include:
- startPrep()
- startDialog()
- startVocab()
- startDrill()
- renderMistakes() + show("mistakes")

Only surface Pronunciation, Saved Words or Review Queue when a real reachable handler/data path exists.

Do not invent functionality to match the visual reference.
