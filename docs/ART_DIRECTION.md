# MARZI Premium Shell Art Direction

The rest of MARZI must feel as intentional as the Gold Call.

## Desired character
Warm, premium, calm, playful without becoming childish, globally coherent, highly readable.

## Do not repeat the rejected Wave-1 pattern
Do not use a generic repeated header of:
`Marzi + three large counter buttons`
on every top-level screen.

Status chips are subordinate context, not global competing calls to action.

## Marzi presence
- Home: companion and recommendation
- Practice: coach
- Talk: invitation to real conversation, then characters become primary
- Store: customization hero
- Profile: minimal; learner/settings take priority

## Navigation
Five tabs remain:
Home / Practice / Talk / Store / Profile.

Talk may receive subtle central emphasis, but not a giant floating-action-button cliché.

## Hierarchy
Do not create walls of identical rectangles.
Prefer:
1 primary action
2–4 supporting actions
compact grouped rows for secondary tasks.

## Mobile density
At 390×844 the learner should understand the current screen and next action without scrolling through a dashboard wall.
