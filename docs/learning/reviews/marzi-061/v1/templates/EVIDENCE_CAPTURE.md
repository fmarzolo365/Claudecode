# Evidence capture template

Evidence is something another person could go and look at. A restatement of your
conclusion is not evidence.

**Review ID:** `marzi-review:marzi-061:<track>:v1`

| Evidence ID | Artifact path | Location | What was done | What was observed | Captured as | Date |
|---|---|---|---|---|---|---|
| `marzi-evidence:marzi-061:<track>:001` | | | | | | |

Evidence IDs match
`^marzi-evidence:marzi-061:(learning-pedagogy|linguistic|accessibility|android-study):[0-9]{3}$`.

## Rules

- Prefer a measurement over an impression: a scroll width, a target size, a
  contrast ratio, a verbatim quote.
- A screenshot proves layout, never comprehension.
- Reference material held under an approved retention policy; do not embed it.
- Store no participant name, contact detail, demographic, or health data.
- If you could not capture evidence for a condition, mark it `NOT_REVIEWED`
  rather than inferring the result.
