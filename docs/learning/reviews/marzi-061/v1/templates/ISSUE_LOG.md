# Issue log template

Copy this into your own evidence record. Do not record issues in the canonical
preparation data.

**Review ID:** `marzi-review:marzi-061:<track>:v1`
**Reviewer:** _not appointed until recorded by the Product Owner_
**Date:** _leave blank until the review actually happens_

| Finding ID | Severity | Category | Artifact path | Location | Evidence | Impact | Recommendation | Disposition | Evidence refs | Owner role | Re-review |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `marzi-finding:marzi-061:<track>:001` | | | | | | | | `OPEN` | | | |

Severity is `BLOCKER`, `HIGH`, `MEDIUM`, `LOW`, or `INFORMATIONAL`.
Disposition is `OPEN`, `ACCEPTED`, `REMEDIATION_PLANNED`, `RESOLVED`,
`DEFERRED`, or `REJECTED_WITH_RATIONALE`.

Every row needs an exact artifact path and location, and at least one evidence
reference. A finding without evidence is an opinion, not a finding.
