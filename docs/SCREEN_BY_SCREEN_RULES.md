# Screen by Screen Rules

## Home
Question: What should I do now?
Hierarchy: greeting/Marzi → one recommendation → journey/progress → today's focus.
Use existing data only. Do not duplicate destination UIs.

## Practice
Question: What should I train?
Hierarchy: Continue → Prepare → Improve/Review → Library.
Only show destinations with real handlers. No six identical cards. My Progress is not a primary Practice tool.

## Talk
Question: Who do I need to talk to, and in what situation?
Hierarchy: Continue conversation → People & places → Recommended situations → All situations.
No Wave-2 state migration yet. `openDrawer()` may remain the All Situations bridge. Gold characters use Gold art, never emoji.

## Store
Question: How do I personalize Marzi?
Hierarchy: Marzi today → featured → categories → owned/more.
Economy/purchase handlers untouched.

## Profile
Question: How is MARZI configured for me?
Hierarchy: learner/progress → Learning → Conversation → Sound & Motion → Account & Plan → Privacy & Support.
No storage-key migration.
