# Practice States / Accessibility

States:
- no mistakes due
- mistakes due
- saved words empty/populated
- review queue empty/populated
- tool unavailable
- offline/local
- recoverable error

Accessibility:
- each tool is a semantic button/link
- 48px target
- count has text equivalent
- selected/due state not color-only
- 200% text grows rows vertically
- RTL logical layout
- no horizontal overflow
